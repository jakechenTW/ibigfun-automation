# iBigFun Automation

Shared domain language for listing reports and their delivery.

## Language

**Report approval**:
Acceptance of a specific report version and its supporting evidence for delivery.
Changes to that report or evidence require renewed acceptance.
_Avoid_: File approval

**Report delivery**:
Sending an approved report through the notifier.
A failure alert is separate from report delivery.
_Avoid_: Run completion
