# Triage labels

Use these exact label strings when a skill names a triage role.

- `needs-triage`: A maintainer must evaluate the issue.
- `needs-info`: The reporter must supply more information.
- `ready-for-agent`: The issue is fully specified for an unattended agent.
- `ready-for-human`: The issue requires human implementation.
- `wontfix`: The issue will not be implemented.
