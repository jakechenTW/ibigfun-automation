# Notification examples

以下內容為虛構示例，僅供檢視格式，不代表實際房源或推薦。
正式通知的標題由 `--title` 提供，程式只把正文寫入 `report.md`。

## 投資候選

標題：`⚠️ 2026-09-20 投資房源｜候選 1 筆待確認`

```markdown
本期有 1 筆候選；成交證據不足，暫留候選，待可比資料補足後重評。

本次取得 4｜推薦 0｜候選 1｜風險 0｜排除 3

### 候選／資料待確認

#### 1. [示例：松江南京站旁二樓](https://example.com/listing)

- 下一步：成交證據不足，待可比資料補足後重評。
- 1800 萬・25 坪・72.0 萬/坪・2/5 樓・屋齡 40 年・台北市中山區
- 🚶 步行約 9 分鐘｜松江南京站 4號出口｜[地圖](https://www.google.com/maps?q=25.052,121.533)
- 🕒 已刊登 34 天
- 官方成交中位約 70.0 萬/坪（4 筆可比；成交證據不足）

### 排除摘要

- 刊登超過上限：2 筆
- 目標捷運站外：1 筆
- 主要原因：刊登超過 365 天上限。
```

## 自住全數排除

標題：`✅ 2026-09-20 自住房源｜無符合物件`

```markdown
本期取得 1 筆房源，因刊登超過上限而排除，沒有待確認物件。

本次取得 1｜符合 0｜候選 0｜風險 0｜排除 1

### 排除摘要

- 刊登超過上限：1 筆
- 主要原因：刊登超過 365 天上限。
```

## 沒有房源

標題：`✅ 2026-09-20 自住房源｜本期無房源`

```markdown
本期未取得符合搜尋條件的房源，沒有待確認物件。

本次取得 0｜符合 0｜候選 0｜風險 0｜排除 0
```

若任一官方來源過期，通知仍須顯示資料限制並使用 `warn`。
物件較多時，先壓縮重複說明，仍須列出全部推薦、候選與風險物件。
